トラックボール付き無線分割キーボード torabo-tsuki をもっと楽しむための、非公式ツール集

⚠️ 開発中の趣味プロジェクトのため、リポジトリ名やツール名は今後変更される可能性があります。 リンクが切れていた場合は、お手数ですがこのページ（torabo-fun）から辿り直してください。ここが常に最新の入口です。

torabo-tsuki （sekigon-gonnoc 氏設計）を日々使う中で「こうだったらいいな」を形にしていった個人製作のツール群です。 ファームウェアの機能を拡張し、その設定をブラウザから再フラッシュ不要で BLE ライブ編集できるようにしています。

どのツールもインストール不要で、ブラウザ（Chrome / Edge）から試せます。

ツール一覧

Torabo-Studio 設定エディタ

ZMK Studio の非公式フォーク。キーマップ編集はそのままに、トラックボール・トラックパッド・ エンコーダ・LED・マクロ・コンボを BLE 経由でライブ編集するタブを追加。設定のバックアップ／復元にも対応。

ブラウザで開く GitHub
トラックボール（慣性スクロール対応） トラックパッド（スワイプ／タップ割り当て） LED（左右独立のルール設定） タップ反応（Hold-Tap／デバウンス）

クリックで原寸表示。これらの設定はすべて BLE 経由で即反映されます（再フラッシュ不要）。

torabo-tsuki_ext_FW 拡張ファームウェア

torabo-tsuki 用の拡張ファームウェア機能モジュール（ZMK モジュール）。使いたい機能をスニペットで個別に ON/OFF でき、必要なファイル一式はブラウザで開くだけの firmware-builder で生成。 PC に開発環境を入れずに GitHub Actions でビルドできます。

firmware-builder を開く GitHub

Torabo-Float キー表示オーバーレイ

「いま押しているキー」と「アクティブレイヤー」を透過・最前面のフローティングウィンドウに リアルタイム表示する Windows 常駐アプリ（Tauri v2）。配信や操作説明のデモ、多レイヤーキーマップの確認に。 Web 版はブラウザで開くだけで動きます。

Web 版を開く GitHub

どれから見ればいい？

  1. キーマップ編集だけなら — いまのファームウェアのまま Torabo-Studio を開いて接続すれば使えます。
  2. トラックボールの速度調整やマクロなど独自機能も使うなら — firmware-builder で拡張ファームウェアをビルドして書き込み → Torabo-Studio の追加タブから設定します。
  3. 押しているキーを画面に出したいなら — 拡張ファームウェア導入後に Torabo-Float を開きます。
