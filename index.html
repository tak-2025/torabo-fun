torabo-fun

torabo-tsuki-lp を日々使う中で「こうだったらいいな」を形にしていった個人製作のツール群です。 ファームウェアの機能を拡張し、その設定をブラウザから再フラッシュ不要でライブ編集できるようにしています。

windowsアプリケーションで構築していたのですが、Web版もできそうなので作ってみました。

2026/9/5 更新　FW・アプリケーションに不具合があったのをいくつか修正しました。

ツール一覧

Torabo-Studio 設定エディタ

ZMK Studioをカスタマイズしたものになります。キーマップに関しては、日本語環境しか使用できないケースのためのJIS設定や、不要なBehaviorを非表示にしています。 その他、オートレイヤー、マクロ・コンボの設定、トラックパッド等拡張機器の設定ができるようにしています。 タブは「編集」（キーマップ／トラックボール／トラックパッド／エンコーダ／マクロ／コンボ／タップ反応／LED）と 「管理」（バックアップ／FW情報）の全10種で、接続したキーボードが対応している機能のタブだけが出ます。 表示言語は日本語 / English を切り替えられます。

ブラウザで開く タブ別の機能紹介（スクリーンショット付き） GitHub

torabo-tsuki_ext_FW 拡張ファームウェア

torabo-tsuki 用の拡張ファームウェア機能モジュール（ZMK モジュール）。使いたい機能をスニペットで個別にON/OFF でき、 ファームウェア作成する際のファイルを更新することでTorabo Studioに対応したファームウェアの作成が可能になります。

firmware-builder を開く GitHub

Torabo-Float キー表示オーバーレイ

レイヤーが変わっている等に苦戦したことがあるので、画面に表示できたらいいなと思い作りました。 また、拡張機能が繋がっているかわからなかったので拡張機能の内容を診断から確認できるようにしています。

🏢 ネットワークで制限される場合があります。：その場合は単一のHTMLでも使えるものを用意していますので、そちらをお使いください。
Web 版を開く 単一 HTML 版 GitHub

使い方

  1. firmware-builder で自分の環境に合わせて設定 — firmware-builder で使いたい機能を選ぶと、ファームウェア作成用の設定ファイルができます。
  2. フォークした設定リポジトリの内容を更新 — 複数のファイルの更新内容に従って自分の設定リポジトリ（フォーク）に反映して、ファームウェアをビルドしてください。 west.ymlに関しては、単純なコピーアンドペーストではないので、説明を確認しながら行ってください。 west.ymlの設定がよくわからない場合は、こちらのものをご参考にしてください。
  3. あとは用途に合わせて — 設定を変えるなら Torabo-Studio、 キーボードの状態を画面で見たいなら Torabo-Float を開きます。
